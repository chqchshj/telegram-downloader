整理向导

          

            
1提取封面
按 Telegram 媒体组关联封面和视频，优先取同组海报，失败时取视频缩略图。

            
2识别文字
用 Hermes/人工 OCR 得到剧名、EP 和置信度，粘贴到 OCR 映射 JSON。

            
3预览整理
先保持“仅预览”开启，生成计划文件检查 skipped / missing。

            
4生成目录
确认无误后关闭仅预览，生成独立硬链接目录，原始下载不动。
